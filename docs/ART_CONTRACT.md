# Shared artwork contract

Original vector illustration library. Page coordinates: 1000 × 1300. Generator modules export `generatePages()` returning ArtPage objects (see src/types.ts). No external imports required except scripts/art/helpers.mjs. Every page must have its own distinct composition, title, stable id and region geometry. Use explicit paths with closed boundaries; use multiple regions for eyes, irises, hair locks, shadow planes, garments and details. Never copy famous characters. Maintain attractive anime proportions. Regions draw in array order, hit-testing occurs in reverse order. Labels must lie within a visible part of their region (later validation adjusts). Colors must be hex; suggested number is index in page.palette + 1. Line width default 2.8; expressive line details in `lines`. Shades optional aligned semitransparent closed paths. Use at least 18 visible regions on Easy, 40 on Medium, 70 on Hard; density and tiny details must differ. Avoid completely occluded regions. Backgrounds may be fillable. `transparent` only true for standalone characters with no background fill.

Generators are run by `node scripts/build-art.mjs` to produce JSON, SVG line art, aligned SVG reference, and lightweight WebP thumbnail. This is source artwork; draw high quality, intentionally composed expressive characters and tasteful scene details. Page ids are globally unique and stable. Each agent owns one generator module only; helpers.mjs is owned by root. All files here are in a brand new project; coding and artwork creation are explicitly authorized by user.
